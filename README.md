# House Price Prediction

A machine learning project for predicting house prices using housing data. The project focuses on data preprocessing, feature selection, and comparing different regression models.

## Project Overview

The dataset contains numerical and categorical features describing residential properties. The data is processed and analyzed before being used to train machine learning models.

The project includes:

- Data preprocessing and handling missing values
- Numerical and categorical feature analysis
- Feature selection
- Data transformation and encoding
- Training and testing machine learning models
- Model evaluation using R²
- 5-fold cross-validation
- Comparison between different regression models

## Models

The project compares two regression models:

- **Ridge Regression**
- **XGBoost Regressor**
